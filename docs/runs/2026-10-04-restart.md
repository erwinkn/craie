# Restart run, 2026-10-04

Craie restarts after a week's pause, to run the shared Marbre
application in a Craie window (Marbre Vision, development step 3). A
coordinator thread splits the work: worker A owns Craie's Rust, wire
and bridge, and worker B, later, the Marbre side (the kit's `.craie`
implementations, the theme resolver, a native app host). Every PR gets
an independent review before it merges (findings in `LEDGER.md`).
The kickoff's milestones are:

1. land #22 and automate `ci.sh`;
2. a runnable kit fixture, with layout and window observations and
   capture;
3. paint and text parity;
4. controlled edits for the composer;
5. lists and menus.

Host: exe1, the same shared Linux VM as the overnight run (8 CPUs, no
GPU: llvmpipe). Its load average was 20 to 31, and its disk filled
twice that morning, from other projects' builds and `/tmp`, until the
coordinator cleared space. Local builds now share one target directory
without incremental compilation, and GitHub Actions (#23) runs `ci.sh`
on every PR and on main. Times are UTC.

## Decisions

- **GitHub Actions is the main verifier.**
  - ubuntu-24.04 runs `ci.sh` with lavapipe and the validation layer, then the smoke test under Xvfb.
  - `CRAIE_REQUIRE_GPU` turns a missing adapter into a failure instead of skipped GPU tests.
  - The token is read-only and the actions are pinned to commits.
  - Without a cache, a run takes about 17 minutes. Only main writes the cargo cache.
- **`ci.sh` builds once per feature set.**
  - It builds the default members as `cargo test` uses them, and the addon as `build-addon.sh` builds it.
  - A `--workspace` build resolved features differently from both, so the test and smoke steps recompiled for minutes.
- **Exits end in linear time** (PR22-09).
  - Running and skipped exits are sorted sets.
  - The events of freed nodes are filtered once, when events are next taken.
  - Unmounting 1,000 exiting toasts does 3,000 visits in validation and 4,000 ending them.
- **Exiting text leaves the selection** (PR22-10), as removed text does.
